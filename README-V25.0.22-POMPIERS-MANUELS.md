# FireMap V25.0.22

Les deux effectifs du Poste de commandement sont maintenant manuels.

- Toucher « Pompiers en intervention » pour entrer le nombre.
- Toucher « Pompiers disponibles » pour entrer le nombre.
- Les nombres sont enregistrés dans l'événement actif.
- Ils sont synchronisés avec l'événement Firebase via le Centre de commandement.
- Chaque modification est ajoutée au journal d'intervention.
- Les nombres ne sont plus calculés à partir des fiches véhicules.
