# V25.0.23
Tous les carrés statistiques du Centre de commandement peuvent être touchés pour corriger/ajuster manuellement leur valeur, notamment lors d'entraide.
Aucune mention « Modifier » n'est affichée.
Carrés: véhicules engagés, sur les lieux, alimentés, pompiers en intervention, pompiers disponibles, sorties actives, cylindres d'air, rehab, décontamination.
Les valeurs manuelles sont enregistrées dans l'événement et journalisées.
