# FireMap V22.3.7 — Fin d’événement réservée au compte 102

## Nouveau fonctionnement

Le bouton `Terminer l’événement` existe uniquement au poste de commandement.

Seul le compte `102 — Chef` peut :
- fermer l’événement;
- déclencher la réinitialisation des fiches des unités.

L’Assistant d’intervention ne possède plus de fonction permettant de terminer l’événement.

Les autres comptes (202, 502, 602, 802 et 902) sont bloqués à la fois dans l’interface et dans le code.
