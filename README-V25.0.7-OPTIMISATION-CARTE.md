# FireMap V25.0.7 — Optimisation carte iPhone

Cette version vise la fluidité du déplacement Leaflet.

## Changements
- tuiles standard (pas Retina 2x);
- `updateWhenIdle` actif;
- animations zoom/fade/markers désactivées;
- rafraîchissements Firebase des marqueurs différés pendant le pan;
- bornes, bâtiments et véhicules actualisés une seule fois après `moveend`;
- pulsations/ombres coûteuses coupées pendant le déplacement;
- cache FireMap conservé entre les ouvertures.

Aucune fonction opérationnelle n'a été retirée.
