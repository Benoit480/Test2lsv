Comment configurer le Raccourci iPhone
  1. Créer une automatisation personnelle déclenchée à la réception d’un message du numéro autorisé.
  2. Ajouter l’action Encoder l’URL avec le contenu du message reçu.
  3. Ajouter l’action Ouvrir les URL avec le lien FireMap copié.
  4. Remplacer TEXTE_ENCODE par la variable du message encodé.
