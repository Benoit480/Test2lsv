# FireMap V25.0.3 — bouton Fiche véhicule

Modification de la barre de navigation inférieure :

- retrait du bouton rouge `+ Ajouter`;
- ajout du bouton central `🚒 Fiche véhicule`;
- le bouton ouvre automatiquement la fiche du véhicule associé au compte actif;
- pour le compte 102, il ouvre la fiche du véhicule 102;
- le bouton `Ajouter` du menu latéral demeure disponible pour ajouter une borne ou un bâtiment.

Fichiers modifiés : `index.html`, `styles.css`, `vehicle-usage.js`, `firemap-boot.js`, `service-worker.js`.
