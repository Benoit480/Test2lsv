# FireMap V25.0.29

- « Pompiers sur les lieux » additionne automatiquement les effectifs des véhicules arrivés ou alimentés.
- Exemple : le 202 « Sur les lieux » avec 6 pompiers affiche maintenant 6 au Dashboard.
- Le carré reste modifiable pour ajouter ou retirer manuellement un effectif d'entraide.
- La valeur se recalcule en direct lorsque les fiches véhicules sont modifiées ou synchronisées.
- Le cache PWA a été renouvelé.
