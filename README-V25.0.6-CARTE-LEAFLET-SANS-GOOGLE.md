# FireMap V25.0.6 — Carte Leaflet sans Google

Cette version remet l'ancienne carte Leaflet comme carte principale.

## Conservé
- Firebase temps réel V25.0.5
- Bornes
- Bâtiments
- Prévention
- Événements
- Fiches véhicules
- Poste de commandement
- Banque d'adresses Louiseville

## Retiré temporairement
- Google Maps
- Google Maps Adapter
- configuration de clé Google

## Important
Le fond de carte Leaflet utilise CARTO/OpenStreetMap. FireMap n'utilise plus Google Maps,
mais les tuiles de fond nécessitent une connexion si elles ne sont pas déjà en cache.
