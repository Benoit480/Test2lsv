# FireMap V25.0.31

- Google Maps, la recherche Google et les itinéraires sont conservés.
- Les bornes-fontaines sont affichées pour les appels liés à un incendie.
- Elles sont masquées sur la carte et dans l'assistant pour les appels clairement non-incendie.
- Si la nature de l'appel est inconnue, elles restent visibles par sécurité.
- À la fermeture de l'intervention, l'affichage normal des bornes est rétabli.
- Le cache PWA a été renouvelé.
