# FireMap V25.0.28

- Le total « Sorties actives » inclut automatiquement toutes les sorties actives des fiches véhicules.
- Une modification manuelle des sorties sert d'ajustement pour les unités d'entraide et ne bloque plus les mises à jour automatiques.
- « Pompiers disponibles » devient « Pompiers sur les lieux ».
- Les effectifs du commandement restent enregistrés dans l'événement et synchronisés entre les appareils.
- Le cache PWA a été renouvelé pour charger la correction sur iPhone et tablette.
